# 0.8.1 交付通道分档（冻结契约）

> 派发方：主控。依据：用户对 0.8.0 的实测反馈（2026-10-29 18:4x）。
> 状态：契约已冻结；实施批运行期间本文件只读。

## 一、要解决的问题

0.8.0 把「主控不得写执行面」写成绝对规则，同时删掉了小任务通道。实测代价：

- 0.8.0 文本批本身：约 30 分钟（契约 4 + 实现 7 + 评审 5 + 修复 6 + 复审 5 + 提交 2），直接改估计 10–15 分钟。
- 固定成本 ≈ 派发词 + 子代理启动 + 报告 + 集成 + 可选评审 = 8–20 分钟/批，与任务大小无关；小任务被切成多批时，固定成本超过工作量。

结论：保留「产出物归属」的控制面/执行面划分，但让**仪式随风险缩放**，不再全有或全无。本批只改注入文本、测试、README、版本；不碰 `gates.mjs` / `plugin.mjs` / `nudge.mjs`。

```
交付通道按风险缩放，不搞全有或全无：控制面（契约/账本/裁决）主控直写；轻批（无契约面、无外部环境，且单文件 ≤20 行或同模式机械改写 ≤5 文件，≤8 分钟）子代理直做，不写 spec、不派独立评审，主控复跑窄命令 + 读 diff；其余为全批（spec 冻结 + 独立评审 + 集成）。有界直改只用于已闭合批次的收尾修复：单文件 ≤10 行、同批累计 ≤20 行，记账并重开受影响评审切片。

```
